# Facebook Clone Website

This project is a **Facebook-inspired website clone** that I created while learning and practicing **Git and GitHub**. The main purpose of this project was to understand how to work with a project using Git, manage changes, create commits, and maintain the project on GitHub.

## 📌 About the Project

This website is designed to replicate the basic look and feel of Facebook's user interface. It was created as a practice project to improve my understanding of **HTML and CSS** while simultaneously learning the fundamentals of **Git and GitHub**.

During the development of this project, I practiced creating and managing files, tracking changes with Git, making commits, and working with a GitHub repository.

## 🎯 Purpose of the Project

The main objectives of this project were:

- Practice building a website using HTML and CSS.
- Learn how to organize a frontend project.
- Understand the basics of Git and version control.
- Learn how to initialize and manage a Git repository.
- Practice using Git commands such as `git add`, `git commit`, `git status`, and `git push`.
- Learn how to upload and manage projects on GitHub.
- Understand how changes are tracked throughout the development process.

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure of the website.
- **CSS3** – Used for styling and designing the user interface.
- **Git** – Used for version control and tracking project changes.
- **GitHub** – Used to host and manage the project repository.

## 📚 What I Learned

While creating this project, I learned and practiced:

- Creating a basic frontend website.
- Structuring HTML pages.
- Styling elements using CSS.
- Organizing project files and folders.
- Initializing a Git repository.
- Tracking files using Git.
- Adding files to the staging area.
- Creating commits with meaningful commit messages.
- Checking project status using Git.
- Connecting a local repository to GitHub.
- Pushing local changes to a remote GitHub repository.
